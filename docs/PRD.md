# 浮屿 Islet — 产品需求文档（PRD）

> Windows 桌面端「原子岛」形态的实时任务胶囊
> 版本：v0.1（MVP 定义）
> 日期：2026-10-25

---

## 1. 一句话定位

**浮屿是 Windows 上唯一一个只显示「此刻最该被看见、且点一下就能办完事」的地方。**

它不常驻仪表盘，不做通知中心，不做搜索框。它是**单槽优先级仲裁器**：同一时刻只呈现一件事，其余排队。

---

## 2. 核心设计原则（不可妥协）

| # | 原则 | 含义 | 反面案例 |
|---|---|---|---|
| P1 | **单槽** | 任何时刻只有一件事占据主槽位 | 顶部横条同时显示 CPU / 网速 / 天气 / 音乐 |
| P2 | **双闸门** | 进入主槽必须同时满足「时效性」与「可操作性」 | 「今日新闻 3 条」——既不紧急也不能一键办完 |
| P3 | **零焦点侵占** | 出现、展开、点击全程不夺取键盘焦点 | 弹窗抢焦点导致用户打字中断 |
| P4 | **事件驱动** | 禁止轮询；空闲 CPU 占用 ≤ 0.3% | 每秒 Timer 刷 CPU 温度 |
| P5 | **可被忽略** | 用户不看它，不影响任何正常工作流 | 强制置顶遮住 IDE 状态栏 |
| P6 | **媒体是地板** | 无其他事件时，媒体控制作为默认静息态 | 无内容时留一个空胶囊 |

> P6 是留存关键：媒体控制覆盖面最大、零适配成本，且天然满足「点一下就完成动作」。

---

## 3. 目标用户与场景

**主用户**：长时间在桌面工作、同时开着音乐 / 下载 / 会议的知识工作者。

| 场景 | 触发 | 岛上呈现 | 一键动作 |
|---|---|---|---|
| 听歌 | SMTC 事件 | 封面 + 标题 + 进度条 | 暂停 / 下一首 |
| 下载大文件 | 文件系统或下载器事件 | 文件名 + 进度环 + 剩余时间 | 打开文件夹 |
| 会议即将开始 | 日历事件 | 会议名 + 剩余分钟 | 加入会议 |
| 番茄钟 | 用户启动 | 倒计时环 | 暂停 / 结束 |
| 内存吃紧 | 性能计数器越界 | 「内存 96%，Chrome 占用 8GB」 | 打开任务管理器 |
| 剪贴板识别 | 剪贴板变更 | 「识别到快递单号 SF123…」 | 复制 / 查快递 |

## 4. 功能范围

### 4.1 P0 — 没有它就不叫浮屿

- **F-01 胶囊外壳**：顶部居中、无边框、圆角、亚克力/云母背景、置顶、不抢焦点、不进 Alt+Tab
- **F-02 形态切换**：`隐藏点` ↔ `紧凑条` ↔ `展开卡` 三态，带液态弹性动效
- **F-03 优先级仲裁引擎**：单槽、抢占、排队、超时退场、冷却去重（详见 §6）
- **F-04 媒体控制（SMTC）**：接管任意支持系统媒体传输的播放器，含封面、进度、播放/暂停/上下曲
- **F-05 倒计时 / 番茄钟**：单实例，支持暂停、结束、到点强提醒
- **F-06 任务进度**：下载 / 解压 / 文件传输进度条 + 完成后「打开文件夹」
- **F-07 全屏自动隐身**：检测全屏独占、演示模式、锁屏，自动隐藏
- **F-08 多显示器跟随**：出现在鼠标所在显示器，每屏独立 DPI 缩放

### 4.2 P1 — 差异化

- **F-09 会议临场提醒**：读取日历，T-5 分钟上岛，一键入会
- **F-10 系统体征异常上岛**：仅在越界时出现（内存 / 磁盘队列 / 电池 / 单进程 CPU）
- **F-11 剪贴板内容识别**：验证码、单号、链接、地址、金额 → 给动作按钮
- **F-12 麦克风 / 摄像头 / 录屏占用指示**
- **F-13 专注模式联动**：上岛时同步勿扰，或按白名单放行

### 4.3 P2 — 生态

- **F-14 手机联动**：来电、验证码、电量、跨设备剪贴板（需配套 Android 端）
- **F-15 插件机制**：第三方以声明式清单注册数据源与动作
- **F-16 主题与位置自定义**：左右上角、屏幕边缘吸附

### 4.4 明确不做（Out of Scope）

| 不做 | 理由 |
|---|---|
| 常驻性能仪表盘 | 退化为 Rainmeter 皮肤，违反 P1 |
| 完整通知中心 | 与系统通知重复，双端都烦 |
| 全局搜索 | PowerToys Run 已占位，无胜算 |
| AI 助手对话入口 | 无模型优势时只是会说话的搜索框 |
| 天气 / 股票 / 新闻 | 违反 P2 双闸门 |

## 5. 交互规格

### 5.1 形态与尺寸

| 形态 | 尺寸（@100% DPI） | 内容 | 进入条件 |
|---|---|---|---|
| 隐藏点 | 8 × 8 px | 仅一个呼吸圆点 | 无活跃事件 / 全屏 / 用户手动隐藏 |
| 紧凑条 | 高 32 px，宽自适应 120–320 px | 图标 + 单行主文案 + 最多 2 个动作按钮 | 有活跃事件但鼠标未悬停 |
| 展开卡 | 宽 380 px，高自适应 | 封面/图标 + 标题 + 副标题 + 进度 + 动作组 | 鼠标悬停或点击紧凑条 |

- 距屏幕顶边 8 px，水平居中于工作区
- 圆角 16 px（紧凑条）/ 20 px（展开卡）
- 背景：Win11 用 `DwmSetWindowAttribute` 的 Mica/Acrylic；Win10 降级为纯色 + 透明度

### 5.2 动效

| 动作 | 时长 | 曲线 |
|---|---|---|
| 点 → 条 | 220 ms | 弹性 `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| 条 → 卡 | 280 ms | 同上 |
| 内容切换（抢占） | 180 ms | 淡出 60 ms + 淡入 120 ms |
| 进度环推进 | 线性，120 ms 插值 | — |

**降级**：系统开启「减少动画」时，全部替换为 80 ms 淡入淡出。

### 5.3 触发与收起

| 行为 | 结果 |
|---|---|
| 鼠标进入胶囊区域 | 展开为卡片 |
| 鼠标离开 400 ms | 收回紧凑条 |
| 无事件 8 秒 | 收回隐藏点 |
| 用户点击隐藏点 | 强制展开为卡片 |
| `Ctrl+Alt+I` 全局热键 | 显示/隐藏切换 |
| `Esc`（卡片聚焦时） | 收起 |

### 5.4 不可打断性

- 窗口样式必须包含 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_LAYERED`
- 显示时调用 `ShowWindow(SW_SHOWNOACTIVATE)`，**绝不**用 `SetForegroundWindow`
- 按钮点击通过 `WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE` 实现「点了但不夺焦」

## 6. 优先级仲裁模型（核心）

### 6.1 事件模型

```csharp
record IslandEvent
{
    string Id;                 // 去重键，同 Id 视为同一事件更新
    IslandSource Source;       // Media / Timer / Progress / Meeting / Health / Clipboard
    string Title;
    string? Subtitle;
    double? Progress;          // 0..1，null 表示无进度
    IslandAction[] Actions;    // 最多 3 个
    int Urgency;               // 0..100，时间敏感度
    int Actionability;         // 0..100，一键完成程度
    TimeSpan? Ttl;             // 存活时长，null 表示持续
    bool Pinned;               // 用户固定
    DateTimeOffset CreatedAt;
}
```

### 6.2 评分公式

```
score = BaseWeight[Source]
      + Urgency      * 0.40
      + Actionability* 0.30
      + (Pinned ? 200 : 0)
      + FreshnessBonus          // 新事件 60 秒内 +10，之后线性衰减到 0
      - RepeatPenalty           // 60 秒内被抢占过 +25
```

**BaseWeight**：

| 来源 | 权重 | 说明 |
|---|---|---|
| Meeting | 80 | 错过有硬代价 |
| Health | 70 | 异常才出现 |
| Timer | 55 | 用户主动启动，意图明确 |
| Progress | 50 | 长任务，需要可查 |
| Clipboard | 45 | 机会型，用户可能不理 |
| Media | 10 | **地板值**，仅在其他为空时显示 |

### 6.3 抢占规则

1. **硬抢占**（无视分差）：会议 T-5 分钟内、电量 < 10%、任务完成瞬间
2. **软抢占**：`新分 > 当前分 + 15`（滞回带，防止抖动）
3. **不抢占**：当前项 `Pinned` 或处于用户交互中（鼠标悬停 / 卡片展开）
4. **队列**：最大 8 项，溢出时丢弃分数最低者
5. **冷却**：被用户手动关闭的事件，60 秒内不再上岛

### 6.4 退场

- TTL 到期 → 淡出，交还槽位给队列最高分
- 队列为空 → 回落媒体（P6）→ 无媒体则隐藏点
- 用户手动关闭 → 进入冷却

## 7. 技术架构

```
Islet.sln
├── src/
│   ├── Islet.Core/          纯逻辑，无 UI 依赖，可单测
│   │   ├── IslandEvent.cs
│   │   ├── IslandSource.cs
│   │   ├── IslandScore.cs
│   │   ├── IIslandProvider.cs
│   │   └── IslandSlotManager.cs   ← 仲裁引擎
│   ├── Islet.App/           WPF 外壳
│   │   ├── App.xaml(.cs)
│   │   ├── Views/IslandWindow.xaml(.cs)
│   │   ├── Views/IslandView.xaml(.cs)
│   │   ├── Interop/NativeMethods.cs
│   │   ├── Services/FullscreenWatcher.cs
│   │   ├── Services/MonitorLocator.cs
│   │   └── ViewModels/IslandViewModel.cs
│   └── Islet.Sources/       数据源实现
│       ├── MediaProvider.cs      (SMTC)
│       ├── TimerProvider.cs
│       └── ProgressProvider.cs
└── tests/
    └── Islet.Core.Tests/    仲裁规则单测
```

### 7.1 关键技术选型

| 需求 | 方案 |
|---|---|
| UI 框架 | C# / WPF / .NET 8 (`net8.0-windows`) |
| 无焦点置顶 | `WS_EX_NOACTIVATE + WS_EX_TOOLWINDOW`，`ShowWindow(SW_SHOWNOACTIVATE)` |
| 圆角与模糊 | `DwmSetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE / DWMWA_SYSTEMBACKDROP_TYPE)` |
| 媒体控制 | `GlobalSystemMediaTransportControlsSessionManager`（需 TFM ≥ `10.0.19041.0`） |
| 全屏检测 | `SHQueryUserNotificationState` + 前台窗口矩形比对 |
| 多屏 DPI | `GetDpiForWindow` + `PerMonitorV2` 清单 |
| 热键 | `RegisterHotKey` + `WM_HOTKEY` |

### 7.2 分层约束

- `Islet.Core` **不得**引用任何 WPF / Win32 类型
- 所有 Provider 实现 `IIslandProvider`，向 `IslandSlotManager` 推事件
- UI 只订阅 `IslandSlotManager.CurrentChanged`

## 8. 非功能需求

| 项 | 指标 |
|---|---|
| 空闲 CPU | ≤ 0.3%（进程均值） |
| 空闲内存 | ≤ 60 MB |
| 冷启动到可交互 | ≤ 800 ms |
| 动画帧率 | ≥ 55 fps |
| 崩溃隔离 | Provider 异常不得导致外壳崩溃，单源熔断 |
| 隐私 | 剪贴板识别仅在本地正则匹配，不上传；不记录历史 |

## 9. 里程碑

|---|---|---|
| **M1** | 胶囊外壳 + 三态动效 + 全屏隐身 + 多屏跟随 | 手动触发可正常显隐，不夺焦，全屏时消失 |

## 10. 风险与取舍

| 风险 | 影响 | 缓解 |
|---|---|---|
| Win10 无 Mica | 视觉降级 | 纯色 + 透明度兜底 |
| SMTC 需 WinRT 互操作 | 构建复杂度上升 | 独立 csproj，失败可整体降级 |
| 用户已有 PowerToys | 功能重叠 | 只做胶囊，不做启动器 |
| 全屏误判 | 游戏中被遮挡 | 双重判定（系统状态 + 窗口矩形） |
| 常驻被卸载 | 留存失败 | 媒体地板态保证「有用」 |

## 11. MVP 验收清单

- [ ] 启动后 1 秒内出现胶囊，不抢焦点
- [ ] 播放音乐时显示封面与进度，按钮可控
- [ ] 启动番茄钟后，倒计时抢占媒体槽
- [ ] 倒计时结束弹出强提醒，可关闭
- [ ] 进入全屏视频 / 游戏，胶囊自动消失
- [ ] 断开副屏后位置自动回到主屏
- [ ] 空闲 5 分钟，CPU 占用 < 0.5%
